# jev-organize — نسخه شخصی WhoisGray

[فارسی](README.fa.md) · [English](README.md)

**یک پوشه از فایل‌های کاری را بررسی و دسته‌بندی کنید، گزارش بگیرید و در صورت نیاز یک نسخه مرتب‌شده بسازید.**

این نسخه شخصی را **WhoisGray** نگهداری می‌کند و از پروژه اصلی [jev-organize](https://github.com/nexibeo/jev-organize) الهام گرفته شده است. این یک اقتباس مستقل است و پروژه اصلی نیست.

ابزار با مدل تصمیم‌گیری [Jev از TypeSafe](https://docs.typesafe.ai) کار می‌کند و از API مستقیم TypeSafe استفاده می‌کند. Jev بر اساس متن فایل درباره دپارتمان، نوع سند، حساسیت، تاریخ، طرف مقابل، داده‌های شخصی و برچسب‌ها تصمیم می‌گیرد.

## چه فایل‌هایی پشتیبانی می‌شوند؟

ابزار می‌تواند پوشه‌ای شامل انواع فایل‌ها را اسکن کند؛ اما فقط فرمت‌های زیر را برای استخراج متن می‌خواند. فایل‌های دیگر صرفاً با نام فایل و مسیر پوشه بررسی می‌شوند و ممکن است برای بازبینی علامت بخورند.

| --- | --- | --- |

## شروع سریع

به Node.js نسخه 22.9 یا جدیدتر و یک [کلید API از TypeSafe](https://console.typesafe.ai/keys) نیاز دارید.

با ثبت‌نام مستقیم در [TypeSafe](https://console.typesafe.ai/) می‌توانید **۵ دلار اعتبار رایگان** دریافت کنید.

```bash
# ابتدا نسخه شخصی این مخزن را clone کنید و وارد پوشه آن شوید.
cp .env.example .env
# مقدار TYPESAFE_API_KEY را در فایل .env تنظیم کنید.
node bin/jev-organize.mjs doctor
```

برای برآورد هزینه و سپس اسکن:

```bash
node bin/jev-organize.mjs scan ~/Documents/company-files --estimate
node bin/jev-organize.mjs scan ~/Documents/company-files
node bin/jev-organize.mjs apply ~/Documents/company-files-organized
```

ابزار پوشه را اسکن می‌کند، محتوای قالب‌های پشتیبانی‌شده را استخراج می‌کند و فایل‌ها را دسته‌بندی می‌کند. گزارش‌ها شامل `catalog.jsonl`، `catalog.csv`، فایل `INDEX.md` و گزارش HTML آفلاین هستند. دستور `apply` فایل‌ها را در پوشه جداگانه کپی یا پیوند می‌دهد و فایل‌های اصلی را جابه‌جا، ویرایش یا حذف نمی‌کند.

## حریم خصوصی و محدودیت‌ها

- متن فایل‌ها پیش از ارسال به TypeSafe تا حد امکان از ایمیل، شماره تلفن، IBAN، شماره کارت، شناسه‌های ملی و رازها پاک‌سازی یا با جای‌نگهدار جایگزین می‌شود.
- با گزینه `--names-only` فقط نام و مسیر فایل ارسال می‌شود؛ دقت دسته‌بندی کاهش پیدا می‌کند.
- داده‌ها و پاسخ‌های cacheشده روی دیسک شما ذخیره می‌شوند.
- برای فایل‌های تصویری، صوتی و ویدئویی محتوای فایل خوانده نمی‌شود.
- برای جلوگیری از هزینه ناخواسته از `--estimate`، `--max-cost` و `--limit` استفاده کنید.

برای فهرست کامل فرمان‌ها، تنظیمات، استفاده با Claude/Codex و جزئیات توسعه، [README انگلیسی](README.md) را ببینید.
