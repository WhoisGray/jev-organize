Rebuild steps for ops-01
1. Create VM from template ubuntu-24-base, 2 vCPU / 4 GB, attach volume ops-data (100 GB).
2. apt update && apt upgrade -y; install python3.12, postgresql-client-16, restic, jq.
3. Create service user: sudo adduser --system --group svc-sync
4. Copy /etc/kbs/sync.env from the backup (restic snapshot tag "etc").
5. Mount the WMS export share: //wms-gw/exports -> /srv/wms/exports (cifs, read-only).
6. Install crontab for svc-sync:
     30 2 * * *  /opt/kbs/sync_stock.py --export /srv/wms/exports/stock_latest.csv
     15 3 * * *  /opt/kbs/backup.sh >> /var/log/kbs-backup.log 2>&1
7. Test: run sync with --dry-run and check the item count (about 480 SKUs).
8. Add the host to uptime monitoring and check the backup job the next morning.
